# vfs-emulator
Конфигурационное управление_попытка_1

## 1 Задание 
Разработать минимальный рабочий REPL-прототип эмулятора терминала:
* Диалог с пользователем в отдельном окне
* Команды заглушки 'Ls' и 'cd', команда завершения - 'exit'
* Масштабирование шрифта с клавиатуры
* Вывод ошибки при попытке передачи переменных в 'exit'


Импорты и переменные:

import tkinter as tk — встроенный модуль для создания графического интерфейса (GUI)

import shlex — модуль для лексического разбора командной строки

First_string — глобальная переменная, содержащая стартовое приглашение к вводу
