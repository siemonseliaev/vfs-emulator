# vfs-emulator
Конфигурационное управление_попытка_1

Импорты и переменные:
import tkinter as tk — встроенный модуль для создания графического интерфейса (GUI)
import shlex — модуль для лексического разбора командной строки (лексер)
First_string — глобальная переменная, содержащая стартовое приглашение к вводу

История коммитов (Conventional Commits):
feat(gui): инициализировать главное окно и графические виджеты терминала
feat(parser): реализовать разбор командной строки с помощью shlex
feat(commands): добавить обработку команд help, cd, ls и exit
fix(parser): исправить опечатку в команде ls и улучшить обработку ошибок
docs(readme): добавить описание проекта и инструкцию по запуску
